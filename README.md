# Curso Básico de Inteligência Artificial Aplicada

Repositório pessoal de conteúdo educacional sobre Inteligência Artificial, desenvolvido como projeto piloto de ensino a distância.

O material aqui publicado é de acesso livre e foi criado no contexto das atividades de instrução na **Escola de Comunicações**, com o objetivo de tornar o aprendizado sobre IA acessível, prático e atualizado.

O conteúdo está em desenvolvimento contínuo, com novos assuntos sendo adicionados progressivamente.

**Acesse o curso em:** https://lpluiz90.github.io/CBIAA/

# Curso Básico de Inteligência Artificial Aplicada

Repositório pessoal de conteúdo educacional sobre Inteligência Artificial, desenvolvido como projeto piloto de ensino a distância.

O material aqui publicado foi criado no contexto das atividades de instrução na Escola de Comunicações, com o objetivo de tornar o aprendizado sobre IA acessível, prático e atualizado para os integrantes da Escola.

O conteúdo está em desenvolvimento contínuo, com novos assuntos sendo adicionados progressivamente com o tempo.
